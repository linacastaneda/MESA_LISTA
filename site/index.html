Aplicación web para gestionar reservas de restaurantes, con acceso para clientes y administradores.

Abrir la aplicación ↗Consultar el diseño ↗

Esta es la presentación del proyecto. La aplicación Flask aún no tiene una dirección pública configurada. Para probarla, sigue el README del repositorio.

01

Reserva con confianza

Horarios disponibles, asignación de mesa y cancelación antes del inicio.

02

Gestiona tu restaurante

Mesas y franjas de atención con protección de las reservas vigentes.

03

Diseño orientado a objetos

Builder, Prototype, Facade y Adapter. Tres capas, DAO y SQLite.

La presentación se puede alojar en GitHub Pages. El login y las reservas se ejecutan en el servidor Flask.
